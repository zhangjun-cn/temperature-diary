# App Store 发布指南（体温日记）

> 本指南针对当前工程（iOS 17.0+、SwiftUI、iPhone-only）编写。
> 打包/签名必须在一台**安装了 Xcode 15+ 的 Mac** 上完成（本工程最低要求 iOS 17，建议 Xcode 15 或 16）。

---

## 0. 前置条件

1. **Apple Developer Program 会员**（$99/年）：https://developer.apple.com/programs/
2. **Xcode 15 或更高版本**，并已用你的 Apple ID 登录（Xcode → Settings → Accounts）。
3. 一个**唯一的 Bundle Identifier**（下面的第 1 步）。

---

## 1. 修改 Bundle ID（必做）

当前工程用的是占位符 `com.example.TempTracker`，上架必须改成你自己的唯一 ID。

建议：`com.zhangjun-cn.temperaturediary`

修改方法：
- 打开 `TempTracker.xcodeproj` → 选中 **TempTracker** Target → **Signing & Capabilities** → 把 **Bundle Identifier** 改成你的 ID。

---

## 2. 签名（Signing）

推荐用 Xcode 的**自动签名**（本工程已设置 `CODE_SIGN_STYLE = Automatic`）：

1. Target → Signing & Capabilities。
2. 勾选 **Automatically manage signing**。
3. **Team** 下拉里选择你的开发者团队（Apple Developer 账号对应的 Team）。
4. 首次 Archive 时，Xcode 会自动创建「iOS Distribution 证书」和「App Store 描述文件」。

> 如果自动签名报错，去 https://developer.apple.com/account → Certificates, Identifiers & Profiles 手动确认：
> - **Identifiers** 里注册了与 Bundle ID 一致的 **App ID**；
> - 有可用的 **iOS Distribution** 证书；
> - 有 **App Store** 类型的 Provisioning Profile。

---

## 3. 打包（Archive）

### 方式 A：Xcode 图形界面（推荐）

1. 顶部设备选择 **Any iOS Device (arm64)**（不要选模拟器）。
2. 菜单 **Product → Archive**。
3. 等构建完成，会自动弹出 **Organizer**。

### 方式 B：命令行

首次用命令行前，先在 Xcode 里打开一次工程，并把 Scheme 设为共享：
Xcode → Product → Scheme → Manage Schemes → 勾选 TempTracker 的 **Shared**。

```bash
cd /path/to/体温记录app

# 清理
xcodebuild clean \
  -project TempTracker/TempTracker.xcodeproj \
  -scheme TempTracker \
  -configuration Release

# 归档
xcodebuild archive \
  -project TempTracker/TempTracker.xcodeproj \
  -scheme TempTracker \
  -configuration Release \
  -archivePath build/TempTracker.xcarchive \
  -destination 'generic/platform=iOS'

# 导出 App Store 的 .ipa（使用 AppStore/ExportOptions.plist，先填 teamID）
xcodebuild -exportArchive \
  -archivePath build/TempTracker.xcarchive \
  -exportPath build \
  -exportOptionsPlist AppStore/ExportOptions.plist
```

---

## 4. 上传到 App Store Connect

### 方式 A：Xcode Organizer（推荐）
1. Organizer 里选中刚生成的 Archive。
2. 点 **Distribute App** → **App Store Connect** → 按向导上传。

### 方式 B：Transporter
- 在 Mac App Store 下载 **Transporter**，把导出的 `.ipa` 拖进去上传。

### 方式 C：命令行
```bash
# 上传 .ipa（会要求 Apple ID / App 专用密码）
xcrun altool --upload-app -f build/TempTracker.ipa -t ios \
  -u "你的AppleID邮箱" -p "App专用密码"
```
> `altool` 已逐步弃用，优先用 Xcode 或 Transporter。

---

## 5. App Store Connect 里的设置

登录 https://appstoreconnect.apple.com：

1. **我的 App → ＋ → 新建 App**：
   - 平台 iOS；
   - 名称「体温日记」；
   - 主语言「简体中文」；
   - Bundle ID 选你注册的那个；
   - SKU 随便填（如 `temperature-diary-001`）。
2. **App 信息**：分类、副标题、年龄分级（见《商店信息》）。
3. **价格与销售范围**：选价格（可免费），地区。
4. **App 隐私**：按问卷如实回答。本 App 不收集任何数据、无广告、无第三方 SDK → 选「不收集数据」。**需提供隐私政策 URL**（见第 6 步）。
5. **准备提交**：
   - 上传 App 截图（见《截图规范》）。
   - 填写**描述、关键词、支持 URL**（见《商店信息》）。
   - **App 审核信息**：填写演示账号（本 App 无需登录，可留空或填「无」）、联系信息。
   - **出口合规**：本 App 未使用加密 → 选「否」。
   - **广告标识符（IDFA）**：本 App 未使用广告 → 选「否」。
6. 全部填完后点 **提交以供审核**。

---

## 6. 支持 URL 与隐私政策 URL

- **支持 URL**：可用你的 GitHub 仓库 https://github.com/zhangjun-cn/temperature-diary ，或一个简单的联系页面。
- **隐私政策 URL**：把《隐私政策》文本放到一个公开网页（比如 GitHub Pages、Notion、语雀），填其 URL。

---

## 7. 常见被拒点（本 App 特别注意）

1. **医疗声明**：App 描述和截图里**不要**写「测温预测排卵 / 避孕 / 诊断 / 治疗」等医疗功效字样，只写「个人记录与参考」。已在本指南的《商店信息》描述里加了免责声明。
2. **年龄分级**：因为包含「性生活记录」，审核问卷里按实回答，可能评为 12+ 或 17+，属正常。
3. **本地通知权限**：App 使用本地通知（测温计时闹铃），无需额外 capability，但要在描述/审核备注里说明用途（已在描述里写了）。
4. **图标**：必须是纯正方形、无透明、无圆角的 1024×1024 原图（`TempTracker/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` 已满足）。
